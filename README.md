Mother’s Day Cinematic Tribute

An immersive cinematic Mother’s Day experience built with Three.js, GSAP, and interactive storytelling principles.

This project transforms a traditional 3D scene into a guided emotional journey featuring:

cinematic camera movement
animated memory sequences
poetic subtitles
floating polaroids
atmospheric particles
synchronized chapter-based storytelling

The experience is designed to feel like a short interactive film dedicated to mothers.

✨ Features
🎬 Cinematic Timeline Experience

A fully automated 2-minute guided experience powered by GSAP timelines.

The camera follows carefully designed cinematic paths while:

subtitles appear dynamically
memories fade in/out
particles react to emotional moments
lighting shifts between chapters
📸 Floating Memory Polaroids

Illustrative “memories” appear as floating polaroids in 3D space.

Included scenes:

Childhood Memory
Sunflowers Field
Reading Together
The Glowing Heart

Each image:

softly animates
glows subtly
fades naturally into the scene
❤️ Heart of Gold Sequence

The emotional centerpiece of the experience.

Features:

intensified particle systems
glowing heart animation
slower cinematic camera focus
emotional subtitle overlays
📝 Poetic Subtitle System

Dynamic subtitle overlays provide emotional storytelling throughout the experience.

Example lines:

“Even the stars could never outshine your warmth.”

🎞 Experience Chapters
1. Intro & Space Voyage (0s – 20s)

The experience begins with a slow cinematic flythrough into space.

Features:

ambient particles
slow zoom-ins
emotional opening subtitles
2. Memories (20s – 60s)

Floating polaroids appear around the user while soft transitions reveal emotional moments.

Features:

memory animations
subtitle storytelling
cinematic fades
depth-of-field inspired motion
3. Heart of Gold (60s – 90s)

The camera focuses on the glowing 3D heart as particles intensify around it.

Features:

emotional climax
increased glow effects
synchronized camera movement
stronger atmosphere
4. Final Message & Credits (90s – 120s)

The experience slowly fades into a heartfelt ending.

Features:

final dedication message
fade-to-dark transition
closing subtitle sequence
